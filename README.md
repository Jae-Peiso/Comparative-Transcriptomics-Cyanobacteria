# Rhythmic gene comparison

This repository captures a small comparative transcriptomics workflow for contrasting rhythmic genes in the Kushige 2013 and Ito 2009 datasets.

## Project goal

The core objective is to characterize analysis hurdles while producing one defensible quantitative comparison of rhythmic genes across the two studies.

## Repository structure

- `PROJECT_BRIEF_rhythmic_gene_comparison.md` — project scope, analysis plan, and hurdle register
- `DOWNLOADS.md` — manual download instructions for the supplementary information
- `hurdles.md` — working log of analysis issues and lessons learned
- `ComparativeTranscriptomics.ipynb` — notebook for exploratory analysis
- `Ito2009/` and `Kushige2013/` — downloaded source materials and related files

## Workflow notes

1. Download the supplementary materials described in `DOWNLOADS.md`.
2. Parse the datasets into a common tidy schema.
3. Compare rhythmic genes using the analysis approach described in the project brief.
